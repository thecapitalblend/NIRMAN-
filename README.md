# Balaji Construction AI

A Streamlit-based construction management foundation for Balaji Construction.

## Phase 1

- Dashboard
- Sites
- Workers
- Owners / Clients
- Daily attendance
- Worker payments and advances
- Site expenses
- Ledger reports
- SQLite database
- CSV/Excel report export

## Run locally

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Streamlit deployment

Set the main file to:

`streamlit_app.py`

## Important

This is a business-management foundation. Vastu, 2D floor-plan generation, 3D, 360° and AI video are intentionally separated for later phases.
